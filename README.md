# soma-nota

Sistema desenvolvido para importar imagens de comprovantes de pagamento e realizar a extração de informações utilizando OCR.

## Funcionalidades

- Importação de imagens
- Extração de valores
- Identificação de métodos de pagamento
- Soma automática dos valores encontrados

## Tecnologias utilizadas

- Python
- Streamlit
- OpenCV
- Tesseract OCR

## Objetivo

O projeto foi criado para automatizar a leitura e organização de comprovantes de pagamento.
